# Muted channel unread attention

The existing resource-view-state list adds `mention_activity_version` (exact surviving structured human-recipient mention position) and `channel_mentions_only` (saved actor/workspace/channel preference, excluding DMs). Raw `activity_version`, `viewed_activity_version`, `unread` and the normal `attention_activity_version` retain their contracts. Clients select the mention position for muted attention and never mark messages read to hide ordinary activity. Unmute restores the underlying projection.

Canonical thread rows add `attention: {policy_version: 1, mention_activity_versions: {<actor UUID>: <resource sequence>}}`. Record-sync clients materialize this alongside the original attention. Tasks/documents reuse their surviving comment/body positions; assignment attention does not become a mention. Chat canonical metadata historically uses `type: agent` even for human recipients, so actual actor kind plus exact structured actor ID (npub only when ID absent) identifies the human recipient. Display text is never routing authority.

Messages store per-recipient positions so later ordinary updates, migration replay and edits adding another recipient cannot revive an already-read mention. New mentions during message revision advance the thread resource sequence; existing recipients retain their old positions. Removed/deleted mentions drop out. Historical positions recover only from exact thread-created source-message or thread-updated reply-message outbox associations. Missing provenance remains neutral. Schema reruns preserve read state and do not publish unchanged projections.

Preferences still use the existing CAS routes and recipient-private notification hint. No new route or ACL grant is introduced. DMs, other actor/workspace partitions, bell categories and push delivery policies retain their existing rules. Client upgrades require the additive server contract for full parity; sparse write acknowledgements may omit the projection and must not erase a cached authoritative mute decision.
